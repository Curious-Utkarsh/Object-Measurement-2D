# Real-Time 2D Object Measurement — OpenCV

Measures the width and height of objects placed on an A4 sheet in real time. The script finds the sheet's contour, warps it to a top-down view, then uses its known size as the scale to measure the objects on it. Computer-vision learning project, 2022.
